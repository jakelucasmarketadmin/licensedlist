# TriVetted Weekly — digest template (GHL email)

Subject: This week in tri-state local: {{new_count}} newly verified businesses

Sections (pull manually or via GHL custom values until automated):

1. **Newly verified** — up to 3 businesses verified this week, each: name, town, category,
   one-line "why we picked them", link to profile.
2. **This weekend** — up to 3 events from /events (title, date, venue, link).
3. **One guide** — the latest or most seasonal guide from /guides (title + 2-sentence hook + link).
4. Footer (required): who we are, why you're receiving this (double opt-in confirmed),
   physical address, one-click unsubscribe. CAN-SPAM applies.

Voice: plain, specific, no hype. Never include a business that isn't published and
verified. Never include sample/DEMO content.
